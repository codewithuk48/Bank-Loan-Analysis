(Bank Loan Analysis Dashboard Power BI Project)

*Project Overview
This project focuses on analyzing bank loan applications, funded amounts, repayments, loan status, customer demographics, and financial risk patterns using Power BI.

The dashboard helps understand:
- Loan approval trends
- Good vs bad loan distribution
- Customer financial behavior
- Loan repayment performance
- Regional and demographic loan insights
- KPI tracking for banking decision-making


*Objectives
- Analyze total loan applications and funded amounts
- Track fully paid, current, and charged-off loans
- Identify high-risk customer categories
- Study customer demographics and employment patterns
- Build interactive dashboards for business decisions
- Generate actionable insights for loan performance improvement


*Tools & Technologies Used
- Power BI
- Power Query
- DAX
- Microsoft Excel / CSV Dataset
- Data Visualization
- Data Cleaning & Transformation


*Key KPIs
#Loan Performance KPIs
- Total Loan Applications
- Total Funded Amount
- Total Amount Received
- Average Interest Rate
- Average DTI (Debt-to-Income Ratio)

#Loan Status Metrics
- Fully Paid Loans
- Current Loans
- Charged-Off Loans
- Good Loan Percentage
- Bad Loan Percentage


*Dashboard Pages
1. Summary Dashboard
Contains:
- Overall KPIs
- Loan status breakdown
- Month-wise trends
- Good vs bad loan comparison
- Funded amount analysis

2. Overview Dashboard
Contains:
- State-wise loan analysis
- Employment length analysis
- Home ownership analysis
- Purpose-wise loan distribution
- Grade and sub-grade analysis

3. Details Dashboard
Contains:
- Customer-level loan details
- Payment behavior
- Loan issue dates
- Interest rate analysis
- Individual loan records


*Business Insights
- Most loans belong to medium-income customers.
- Charged-off loans contribute significantly to financial risk.
- Customers with lower employment length show comparatively higher default probability.
- Debt-to-income ratio directly impacts repayment capability.
- Certain loan purposes generate higher default rates.
- Monthly loan applications show seasonal fluctuations.


*Recommendations
1. Improve Risk Assessment
   - Strengthen credit evaluation for high-risk borrowers.

2. Focus on DTI Ratio
   - Avoid approving loans with extremely high debt-to-income ratios.

3. Monitor Loan Purpose
   - Introduce stricter validation for risky loan categories.

4. Employment Verification
   - Give preference to customers with stable employment history.

5. Predictive Analytics
   - Implement machine learning models for default prediction.

6. Customer Segmentation
   - Create customized loan products for different customer groups.
